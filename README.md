# Multiomics-Clusters-Reservoir-2000HIV

This repository is intended to host the analysis scripts used in the manuscript:

**"“Multi-Omics Clustering Differentiates the Total and Intact HIV Reservoirs and Related Host Immune Mechanisms""**

submitted to *Nature*.

## Overview
The analyses in this study were performed using custom R and Python scripts that apply previously published and well-established statistical and machine-learning packages. No new analytical methods or software tools were developed.

All analytical steps, parameters, and packages are described in detail in the Main Text and Methods sections of the manuscript to ensure reproducibility.

## Current status
At the time of initial submission, this repository serves as a placeholder to comply with journal code-availability requirements if code is requested.

The analysis scripts will be added:
- for editorial and peer-review purposes if requested, and  
- publicly upon acceptance of the manuscript.

## Reproducibility
The code relies on publicly available R and Python packages, which are cited in the manuscript. Scripts will be provided in a structured and documented form to allow reproduction of the main analyses and figures.
