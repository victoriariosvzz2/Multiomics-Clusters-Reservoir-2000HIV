Each `figureN/` folder contains:
- The final figure image (`Main Figures_Figure N - ....png`)
- A `README_...` describing the source data workbook (figure1 has neither, since it's a schematic overview with no underlying quantitative data)
- A `SourceData_....xlsx` workbook with the exact values underlying the figure

For how each source data workbook was generated, see the corresponding
script(s) in the "Generated by" column above.
