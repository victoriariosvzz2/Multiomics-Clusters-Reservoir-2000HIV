# Main Figures

Final manuscript figures. Each `figureN/` folder contains the figure image
and a README describing the underlying source data (following the
journal's standard source-data README format: overview, sheet contents,
column definitions, data processing, and code availability).

**Source data workbooks are not included in this public repository during
peer review.** They are provided directly to editors and reviewers upon
request, and will be added to this repository upon publication, consistent
with the journal's source data requirements.

Each `figureN/` folder currently contains:
- The final figure image (`Main Figures_Figure N - ....png`)
- A `README_...` describing the corresponding source data workbook's
  structure and columns (figure1 has neither, since it's a schematic
  overview with no underlying quantitative data)

For how each source data workbook was generated, see the corresponding
script(s) in the "Generated by" column above.
